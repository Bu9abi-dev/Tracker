# Output Patterns

## Prediction brief

- Seed material
- Scenario summary
- Key entities and relationships
- Likely trajectory
- Alternative branches
- Confidence and caveats

## Simulation plan

- Objective
- Seed inputs
- Ontology sketch
- Agent roles
- Memory / environment assumptions
- Interaction rules
- Stop conditions

## Report outline

- Executive summary
- What the seed material implies
- Turning points
- Competing futures
- What would change the outcome
- Evidence trail

## Interview prompts

- Ask for motivations, constraints, alliances, and reactions to shocks
- Probe divergence between public statements and internal incentives
- Ask follow-ups that expose hidden dependencies or weak signals
